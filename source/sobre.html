📘 Descricao do Cenario

Este projeto simula a infraestrutura de uma rede social de compartilhamento de fotos, operada em um ambiente Linux containerizado com Docker. A aplicacao precisa de um servidor web para servir o conteudo estatico, um pipeline para processar imagens enviadas pelos usuarios (gerando thumbnails via ImageMagick), controle de permissoes por perfil de acesso e rotinas automatizadas de backup e monitoramento.

O ambiente foi desenvolvido simulando o papel de um profissional DevOps junior responsavel por preparar, automatizar e documentar toda a infraestrutura operacional da plataforma.

🔧 Tecnologias Utilizadas

Docker + Docker ComposeContainerizacao e orquestracao do ambiente Ubuntu
Ubuntu 22.04 LTSSistema operacional base do container
Apache2Servidor web para publicacao do site estatico
ImageMagickProcessamento e geracao de thumbnails de fotos
Shell Script (Bash)Automacao de todas as rotinas operacionais
GitHub + DockerHubVersionamento e publicacao da imagem Docker

🚀 Como Executar

  • Clone o repositorio: git clone <url>
  • Entre na pasta: cd trabalho03-cloud-shell
  • Suba o container: docker compose up -d --build
  • Acesse o container: docker exec -it trabalho03-linux bash
  • Execute o menu: cd /app/scripts && ./menu.sh
  • Acesse o site: http://localhost:8080
